# Sales Performance Analytics

End-to-end data analytics project developed to analyze commercial performance, profitability and sales opportunities.

## Business Problem

How is the company's commercial performance and which products, customers, salespeople and regions represent the greatest opportunities?

## Tools

- SQL
- Power BI
- Excel
- Python
- Pandas

## Current Analysis

- Revenue analysis
- Profitability analysis
- Regional performance
- Salesperson performance
- Product analysis
- Customer analysis

## Repository Structure

- `data/raw/` — original dataset
- `sql/` — SQL queries developed throughout the project
- `powerbi/` — Power BI files and dashboard deliverables
- `python/` — Python notebooks and scripts
- `images/` — dashboard screenshots
- `docs/` — supporting documentation
